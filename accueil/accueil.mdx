# EASYTRANSFERT BUSINESS API

**Guide développeur officiel**

Bienvenue sur la documentation complète de l'API EASYTRANSFERT BUSINESS. Cette API REST permet aux partenaires d'initier et de suivre des transactions Mobile Money à partir de leurs systèmes (applications web, mobiles ou back-office).

## 🎯 Objectif de l'API

L'API EASYTRANSFERT BUSINESS est conçue pour :

<CardGroup cols={2}>
  <Card title="Automatiser les opérations Cashin" icon="arrow-up" href="/documentation/introduction/presentation-api">
    Encaissement d'argent sur les wallets Mobile Money
  </Card>
  <Card title="Automatiser les opérations Cashout" icon="arrow-down" href="/documentation/introduction/presentation-api">
    Décaissement d'argent depuis les wallets Mobile Money
  </Card>
  <Card title="Notifications asynchrones" icon="bell" href="/documentation/demarrage-rapide/reception-ipn">
    Réception de notifications de statut via IPN (Instant Payment Notification)
  </Card>
  <Card title="Suivi en temps réel" icon="chart-line" href="/documentation/api-transactions/guide-api">
    Suivi complet des transactions avec identifiants uniques
  </Card>
</CardGroup>

## 🚀 Démarrage rapide

<Card title="Démarrage rapide" icon="rocket" href="/documentation/demarrage-rapide/vue-ensemble-flux" color="#1d60d5">
  Effectuez votre première transaction fonctionnelle en moins de 10 minutes avec notre guide étape par étape.
</Card>

<Steps>
  <Step title="Préparer l'environnement">
    Configurez vos variables d'environnement (base_url, api_key, ipn_url)
  </Step>
  <Step title="Initier une transaction">
    Envoyez une requête POST pour initier une transaction Cashin ou Cashout
  </Step>
  <Step title="Recevoir la notification IPN">
    Réception automatique du statut final (SUCCESS ou FAILED) via webhook
  </Step>
  <Step title="Vérifier le statut (optionnel)">
    Consultation ponctuelle uniquement en cas de besoin
  </Step>
</Steps>

## 📋 Services couverts

L'API couvre exclusivement les services suivants :

### Transferts d'argent Mobile Money

Initiation de transactions Mobile Money via un point d'accès unique.

**Support des opérations :**

- **Cashin** : ajout d'argent sur le wallet Mobile Money du destinataire
- **Cashout** : retrait d'argent depuis le wallet Mobile Money du destinataire

**Support multi-opérateurs via des service_id distincts :**

<CardGroup cols={4}>

</Info>

## ⚠️ Limitations fonctionnelles

<Warning>
  L'API ne fournit pas :
  - d'API de gestion des clients
  - d'API de gestion des bénéficiaires
  - d'API de consultation de solde ou de wallet business
  - de mécanisme de signature cryptographique des IPN (hash non exploité)
  
  Ces fonctionnalités pourront être introduites dans des versions ultérieures.
</Warning>
