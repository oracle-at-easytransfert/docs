## Structure des erreurs

L'API KAYBIC AFRICA retourne des erreurs dans un format standardisé :

| Nom du champ     | Description                                                               |
| ---------------- | ------------------------------------------------------------------------- |
| `transaction_id` | Il s'agit de l'identifiant unique de la requête qui a été effectuée       |
| `error`          | Message d'erreur donnant la raison pour laquelle la transaction a échouée |

### Exemple d'erreur

```json
{
    "transaction_id": "req_RRg_xtA55q32PLIWYVLFL",
    "error": "customer insufficient funds"
}
```

## États possibles

| status         | description                                 |
| -------------- | ------------------------------------------- |
| **SUCCESSFULFUL** | La transaction s'est bien passée            |
| **PENDING**    | La transaction est en attente de validation |
| **FAILED**     | La transaction a échoué                     |
