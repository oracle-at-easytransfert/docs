## URL de base et endpoints

### Base URL

```
http://proxy-airtime.easytransfert.app/api_v1/transaction
```

### Endpoints disponibles

| Endpoint | Méthode | Description |
|----------|---------|-------------|
| `/airtime` | POST | Initier une transaction Cashin ou Cashout |
| `/status` | POST | Consulter le statut d'une transaction |

## Structure des requêtes

### Paramètres communs

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `api_key` | string | Oui | Clé API EASYTRANSFERT |
| `amount` | int | Oui | Montant en FCFA (multiple de 100) |
| `destination` | string | Oui | Numéro au format local sans indicatif (ex: 0103444777) |
| `service_id` | int | Oui | Identifiant du service selon opérateur et type |
| `ipn_url` | string | Oui | URL pour recevoir la notification IPN |
| `custom_data` | string | Non | Données personnalisées pour traçabilité |
| `om_otp` | string | Conditionnel | Code OTP pour Orange Money Cashout uniquement |

## Structure des réponses

### Format standard

```json
{
    "status": "success|error",
    "message": "Message descriptif",
    "data": { ... }
}
```

### Réponse /airtime (succès)

```json
{
    "status": "success",
    "message": "Transaction initiée avec succès",
    "data": {
        "transaction_id": "EFB.144358",
        "amount": 1000,
        "destination": "0500156008",
        "state": "PENDING",
        "custom_data": "ref_123"
    }
}
```

<Warning>
  La réponse immédiate indique que la requête a été acceptée, mais ne confirme pas le succès final. La confirmation arrive via IPN.
</Warning>

### Réponse /status

| Champ | Type | Description |
|-------|------|-------------|
| `transaction_id` | string | Identifiant unique |
| `state` | string | SUCCESS, FAILED, PENDING, CANCELLED |
| `reponse` | string | Message de confirmation (si succès) |
| `error` | string | Message d'erreur (si échec) |
| `amount` | int | Montant de la transaction |
| `custom_data` | string | Données personnalisées |

## Validation et contraintes

### Montant (amount)
- Doit être un entier positif
- **Multiple de 100** (ex: 500, 1000, 1500)
- Respecter les plafonds (min: 500, max: 500 000)

### Destination
- Format local **sans indicatif international**
- Doit correspondre à l'opérateur du service_id
- Format recommandé : 10 chiffres pour la Côte d'Ivoire

### IPN URL
- Doit être accessible publiquement
- HTTPS recommandé en production
- Doit répondre rapidement avec HTTP 200

## Limitations techniques

### Caractères spéciaux

**Recommandation :** Utiliser des caractères alphanumériques et tirets/underscores. Encoder en UTF-8.

### Limites de taille

Pour connaître les limites exactes, testez avec une clé API de test ou contactez le support.

## Bonnes pratiques

- **Valider avant envoi** : Vérifier montant, numéro, service_id avant l'envoi
