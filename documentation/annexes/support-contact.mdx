## Processus de support technique

### 1. Création d'un ticket

<Steps>
  <Step title="Se connecter">
    Connectez-vous au portail développeur.
  </Step>
  <Step title="Sélectionner la catégorie">
    Sélectionnez la catégorie : Bug, Question API, Demande de fonctionnalité, Problème IPN.
  </Step>
  <Step title="Remplir le formulaire">
    Remplissez le formulaire avec :
    - API Key utilisée
    - Endpoint concerné (ex: /airtime, /status)
    - Description détaillée du problème
    - Logs ou captures si disponibles
  </Step>
  <Step title="Recevoir le numéro de ticket">
    Un numéro de ticket unique est généré (ex: EFB-SUPPORT-20260113-001).
  </Step>
</Steps>

### 2. Prise en charge

Les tickets sont triés selon leur urgence :

<CardGroup cols={3}>
  <Card title="Critique" icon="exclamation-triangle" color="#dc2626">
    Production bloquée : réponse sous 1h
  </Card>
  <Card title="Haute" icon="arrow-up" color="#f59e0b">
    Impact sur l'intégration : réponse sous 4h
  </Card>
  <Card title="Normale" icon="info-circle" color="#1d60d5">
    Question générale : réponse sous 24h
  </Card>
</CardGroup>

Un ingénieur support est assigné et contacte le demandeur via email.

### 3. Suivi

<Card title="Suivi du ticket" icon="eye">
  Chaque ticket peut être suivi via le portail ou via email. Des mises à jour régulières sont envoyées jusqu'à résolution complète.
</Card>

### 4. Clôture

<Card title="Résolution" icon="check-circle" color="#16a34a">
  Après résolution, le ticket est clôturé. Le demandeur peut laisser un retour ou demander un suivi complémentaire.
</Card>

## Service Level Agreement (SLA) – Support API

| Niveau | Temps de réponse | Temps de résolution cible |
|--------|-----------------|---------------------------|
| **Critique** | < 1h | < 4h |
| **Haute** | < 4h | < 24h |
| **Normale** | < 24h | < 72h |

<Info>
  Les incidents liés à des erreurs côté client (mauvaise configuration Postman, variables incorrectes, IPN non accessible) sont traités dans le même délai mais peuvent nécessiter un échange avec le développeur.
</Info>
