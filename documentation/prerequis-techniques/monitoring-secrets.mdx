## Monitoring et observabilité

<Warning>
  Aucune métrique spécifique de monitoring ou d'observabilité n'est fournie par KAYBIC AFRICA.
</Warning>

**Recommandations :**
- Mettre en place votre propre système de monitoring pour suivre les transactions
- Surveiller les volumes de transactions, les taux d'erreur et les temps de réponse
- Configurer des alertes pour les erreurs critiques (429, 500, transactions FAILED)
- Conserver les logs de toutes les transactions pour audit et traçabilité

## Gestion des secrets

### Clés API

| Aspect | Description |
|--------|-------------|
| **Obtention** | Les clés API sont obtenues en contactant le support KAYBIC AFRICA |
| **Gestion** | Les clés API sont gérées en contactant le support |
| **Stockage** | Stocker les clés de manière sécurisée (variables d'environnement, gestionnaire de secrets) |
| **Rotation** | Pour obtenir de nouvelles clés ou remplacer des clés, contactez le support |

<Info>
  Pour obtenir ou gérer vos clés API, contactez le support KAYBIC AFRICA via les canaux dédiés (groupe WhatsApp, email support).
</Info>

### Bonnes pratiques

- **Ne jamais exposer** : Ne jamais exposer les clés API côté frontend ou dans des logs accessibles publiquement
- **Variables d'environnement** : Utiliser des variables d'environnement pour stocker les clés API
- **Gestionnaires de secrets** : En production, utiliser des gestionnaires de secrets (Vault, Secret Manager, etc.)
- **Rotation régulière** : Prévoir une rotation régulière des clés API pour limiter l'impact d'une éventuelle compromission

<Tip>
  Dans Testeur d'API, définissez `api_key` comme variable d'environnement de type secret pour éviter toute exposition accidentelle.
</Tip>
