Le **Cashout** permet de retirer de l'argent depuis le wallet Mobile Money du client vers votre compte partenaire EASYTRANSFERT.

## Endpoint principal

```
POST {{base_url}}/airtime
```

## Headers requis

```
Content-Type: application/json
Accept: application/json (recommandé)
```

## Principe du Cashout

- **Source des fonds** : Le wallet Mobile Money du client
- **Destination** : Votre compte partenaire EASYTRANSFERT
- **Prérequis** : Le wallet du client doit avoir suffisamment de fonds

## Paramètres de la requête

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `amount` | int | Oui | Montant de la transaction en FCFA. **Doit être un multiple de 100** (ex: 500, 1000, 1500). |
| `api_key` | string | Oui | Clé API EASYTRANSFERT valide pour authentification. |
| `destination` | string | Oui | Numéro du client au format local **sans indicatif international** (ex: 0701234567 pour Orange, 0103444777 pour MTN). |
| `service_id` | int | Oui | Identifiant du service Cashout selon l'opérateur (voir tableau ci-dessous). |
| `ipn_url` | string | Oui | URL pour recevoir la notification IPN (webhook). **Obligatoire** pour la confirmation finale. |
| `custom_data` | string | Non | Données personnalisées pour identifier la transaction dans votre système (ID commande, référence facture, etc.). Cette valeur sera retournée dans l'IPN. |
| `om_otp` | string | Conditionnel | **Uniquement pour Orange Money Cashout** (service_id 23, 27, 29). Code d'autorisation du débit obtenu par le client. |

<Warning>
  Le montant (`amount`) doit être un **multiple de 100**. Les montants comme 123, 456, 789 seront rejetés.
</Warning>

<Warning>
  **Orange Money Cashout nécessite un OTP** : Pour les Cashout Orange Money (service_id 23, 27, 29), vous devez fournir le paramètre `om_otp` (code d'autorisation du débit).
</Warning>

<Tip>
  Le champ `custom_data` est très utile pour faire le lien entre la transaction EASYTRANSFERT et votre système interne (ID commande, référence facture, etc.). Cette valeur sera retournée dans l'IPN.
</Tip>

## Service ID pour Cashout

| Opérateur | Pays | Service ID | Variable Testeur d'API | OTP requis |
|-----------|------|------------|------------------------|------------|
| MTN | Côte d'Ivoire | `25` | `service_id_mtn_ci_cashout` | Non |
| Orange | Côte d'Ivoire | `27` | `service_id_orange_ci_cashout` | **Oui** |
| Moov | Côte d'Ivoire | `13` | `service_id_moov_ci_cashout` | Non |
| Wave | Côte d'Ivoire | `17` | `service_id_wave_ci_cashout` | Non |
| Trésor Money | Côte d'Ivoire | `19` | `service_id_tresor_ci_cashout` | Non |
| Orange | Sénégal | `23` | `service_id_orange_sn_cashout` | **Oui** |
| Wave | Sénégal | `21` | `service_id_wave_sn_cashout` | Non |

## Paramètre spécial : `om_otp` (Orange Money uniquement)

Pour les transactions Cashout Orange Money, le client doit obtenir un code d'autorisation :

- **Côte d'Ivoire** : Le client compose `#144*82#` sur son téléphone
- **Sénégal** : Le client compose `#144#391#` sur son téléphone

Ce code OTP doit être transmis dans le paramètre `om_otp` de la requête.

**Exemple de code OTP** : Si le client reçoit le code `1234`, vous devez envoyer `"om_otp": "1234"` (en chaîne de caractères).

<Info>
  Pour Orange Money Cashout, le paramètre `om_otp` est **obligatoire**. Sans ce code, la transaction sera rejetée.
</Info>

## Exemples de requêtes

### Exemple 1 : Cashout MTN (Côte d'Ivoire)

```json
{
    "amount": 3000,
    "api_key": "{{api_key}}",
    "destination": "0103444777",
    "service_id": 25,
    "ipn_url": "{{ipn_url}}",
    "custom_data": "payment_order_456"
}
```

### Exemple 2 : Cashout Orange (Côte d'Ivoire) avec OTP

```json
{
    "amount": 5000,
    "api_key": "{{api_key}}",
    "destination": "0701234567",
    "service_id": 27,
    "ipn_url": "{{ipn_url}}",
    "custom_data": "withdrawal_ref_789",
    "om_otp": "1234"
}
```

### Exemple avec cURL (Orange Money avec OTP)

```bash
curl -X POST "{{base_url}}/airtime" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 5000,
    "api_key": "votre_cle_api",
    "destination": "0701234567",
    "service_id": 27,
    "ipn_url": "https://votre-site.com/webhook/easytransfert",
    "custom_data": "withdrawal_ref_789",
    "om_otp": "1234"
  }'
```

## Réponse immédiate

<Warning>
  La réponse immédiate ne confirme **pas** le succès final de la transaction. Elle indique seulement que la requête a été reçue et acceptée par l'API.
</Warning>

**Exemple de réponse :**

```json
{
  "status": "success",
  "data": {
    "transaction_id": "EFB.001158"
  }
}
```

<Info>
  Le `transaction_id` doit être sauvegardé côté application. Il sera utilisé pour :
  - Faire le lien avec la notification IPN
  - Consulter le statut si nécessaire via l'endpoint `/status`
  - Le rapprochement comptable
</Info>

## Confirmation finale

La confirmation finale du statut de la transaction (SUCCESS ou FAILED) est envoyée via :

- **IPN (Webhook)** : Mécanisme recommandé, notification automatique envoyée à votre `ipn_url`
- **Endpoint /status** : Consultation ponctuelle uniquement en cas de besoin (non-réception d'IPN)

<Tip>
  Privilégiez toujours le mécanisme IPN pour connaître le statut final. L'endpoint /status doit être utilisé uniquement en cas de non-réception d'IPN.
</Tip>

## Points importants

- Le numéro `destination` doit correspondre à un compte Mobile Money actif avec suffisamment de fonds
- Pour Orange Money, le client doit avoir généré l'OTP avant l'initiation de la transaction
- Le montant sera débité du wallet du client et crédité sur votre compte partenaire
- La confirmation finale arrive via IPN avec le statut SUCCESS ou FAILED
