Le **Cashin** permet d'ajouter de l'argent sur le wallet Mobile Money du destinataire depuis votre compte partenaire EASYTRANSFERT.

## Endpoint principal

```
POST {{base_url}}/airtime
```

## Headers requis

```
Content-Type: application/json
Accept: application/json (recommandé)
```

## Principe du Cashin

- **Source des fonds** : Votre compte partenaire EASYTRANSFERT
- **Destination** : Le wallet Mobile Money du bénéficiaire
- **Prérequis** : Votre compte partenaire doit avoir suffisamment de fonds

<Warning>
  **Solde partenaire requis** : Pour effectuer un Cashin, votre compte partenaire EASYTRANSFERT doit avoir suffisamment de fonds. Vérifiez votre solde avant d'initier la transaction.
</Warning>

## Paramètres de la requête

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `amount` | int | Oui | Montant de la transaction en FCFA. **Doit être un multiple de 100** (ex: 500, 1000, 1500). |
| `api_key` | string | Oui | Clé API EASYTRANSFERT valide pour authentification. |
| `destination` | string | Oui | Numéro du bénéficiaire au format local **sans indicatif international** (ex: 0103444777 pour Orange, 0670123456 pour MTN). |
| `service_id` | int | Oui | Identifiant du service Cashin selon l'opérateur (voir tableau ci-dessous). |
| `ipn_url` | string | Oui | URL pour recevoir la notification IPN (webhook). **Obligatoire** pour la confirmation finale. |
| `custom_data` | string | Non | Données personnalisées pour identifier la transaction dans votre système (ID commande, référence facture, etc.). Cette valeur sera retournée dans l'IPN. |

<Warning>
  Le montant (`amount`) doit être un **multiple de 100**. Les montants comme 123, 456, 789 seront rejetés.
</Warning>

<Tip>
  Le champ `custom_data` est très utile pour faire le lien entre la transaction EASYTRANSFERT et votre système interne (ID commande, référence facture, etc.). Cette valeur sera retournée dans l'IPN.
</Tip>

<Info>
  **Note historique** : Certaines documentations mentionnent les service_id 10, 12, 14, 16 pour MTN, Orange, Moov, Flooz. Ces identifiants peuvent varier selon la région. Consultez la page [Services](/documentation/services) pour la liste complète et à jour.
</Info>

## Exemples de requêtes

### Exemple 1 : Cashin MTN (Côte d'Ivoire)

```json
{
    "amount": 5000,
    "api_key": "{{api_key}}",
    "destination": "0103444777",
    "service_id": 24,
    "ipn_url": "{{ipn_url}}",
    "custom_data": "deposit_order_12345"
}
```

### Exemple 2 : Cashin Orange (Côte d'Ivoire)

```json
{
    "amount": 10000,
    "api_key": "{{api_key}}",
    "destination": "0701234567",
    "service_id": 26,
    "ipn_url": "{{ipn_url}}",
    "custom_data": "transfer_ref_789"
}
```

### Exemple avec cURL

```bash
curl -X POST "{{base_url}}/airtime" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 5000,
    "api_key": "votre_cle_api",
    "destination": "0103444777",
    "service_id": 24,
    "ipn_url": "https://votre-site.com/webhook/easytransfert",
    "custom_data": "deposit_order_12345"
  }'
```

## Réponse immédiate

<Warning>
  La réponse immédiate ne confirme **pas** le succès final de la transaction. Elle indique seulement que la requête a été reçue et acceptée par l'API.
</Warning>

**Exemple de réponse :**

```json
{
  "status": "success",
  "data": {
    "transaction_id": "EFB.001158"
  }
}
```

<Info>
  Le `transaction_id` doit être sauvegardé côté application. Il sera utilisé pour :
  - Faire le lien avec la notification IPN
  - Consulter le statut si nécessaire via l'endpoint `/status`
  - Le rapprochement comptable
</Info>

## Confirmation finale

La confirmation finale du statut de la transaction (SUCCESS ou FAILED) est envoyée via :

- **IPN (Webhook)** : Mécanisme recommandé, notification automatique envoyée à votre `ipn_url`
- **Endpoint /status** : Consultation ponctuelle uniquement en cas de besoin (non-réception d'IPN)

<Tip>
  Privilégiez toujours le mécanisme IPN pour connaître le statut final. L'endpoint /status doit être utilisé uniquement en cas de non-réception d'IPN.
</Tip>

## Points importants

- Le numéro `destination` doit correspondre à un compte Mobile Money actif de l'opérateur sélectionné
- Le montant sera débité de votre compte partenaire et crédité sur le wallet du bénéficiaire
- La confirmation finale arrive via IPN avec le statut SUCCESS ou FAILED
- Aucun OTP n'est requis pour les transactions Cashin
