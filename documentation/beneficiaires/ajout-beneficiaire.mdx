description: "Comment créer un nouveau bénéficiaire pour vos transactions"

---

Permet de créer un nouveau bénéficiaire qui pourra ensuite être utilisé comme destination dans les transactions (Cashin / Cashout). Le bénéficiaire peut être associé à un service spécifique (MTN, Orange, Moov, Flooz).

<Warning>
  **Note importante :** La gestion des bénéficiaires peut ne pas être disponible dans la version v1 de l'API. Vérifiez la disponibilité de cette fonctionnalité avec le support EASYTRANSFERT.
</Warning>

## Endpoint

```
POST {{base_url}}/beneficiaries
```

## Headers

| Nom | Valeur | Description |
|-----|--------|-------------|
| `Content-Type` | `application/json` | Format de la requête JSON |

## Body JSON (exemple)

```json
{
  "api_key": "{{api_key}}",
  "name": "John Doe",
  "phone": "0670123456",
  "service_id": "{{service_id_mtn_cashout}}",
  "custom_data": "client_ref_001"
}
```

## Paramètres détaillés

| Champ | Type | Obligatoire | Description |
|-------|------|-------------|-------------|
| `api_key` | string | Oui | Votre clé API EASYTRANSFERT |
| `name` | string | Oui | Nom complet du bénéficiaire |
| `phone` | string | Oui | Numéro du bénéficiaire au format local (ex: 0670123456) |
| `service_id` | string | Oui | ID du service utilisé (ex: service_id_mtn_cashout) |
| `custom_data` | string | Non | Données personnalisées pour identifier ce bénéficiaire |

## Réponse (exemple succès)

```json
{
  "status": "success",
  "message": "Bénéficiaire créé avec succès",
  "data": {
    "beneficiary_id": "BEN.123456",
    "name": "John Doe",
    "phone": "0670123456",
    "service_id": "11",
    "custom_data": "client_ref_001",
    "created_at": "2026-01-13T12:00:00.000+00:00"
  }
}
```

## Explications

<CardGroup cols={2}>
  <Card title="beneficiary_id" icon="fingerprint">
    Identifiant unique du bénéficiaire. À utiliser pour mettre à jour, supprimer ou lier à une transaction.
  </Card>
  <Card title="Informations principales" icon="user">
    name, phone et service_id sont les informations principales du bénéficiaire.
  </Card>
  <Card title="custom_data" icon="link">
    Utile pour tracer vos bénéficiaires dans votre système interne.
  </Card>

## Conseils pratiques

<CardGroup cols={2}>
  <Card title="Vérifier le format" icon="check-circle">
    Toujours vérifier que phone est correctement formaté pour le service mobile choisi.
  </Card>
  <Card title="Service ID correct" icon="cog">
    service_id doit correspondre au type de transaction prévue (Cashin ou Cashout).
  </Card>
  <Card title="Conserver l'ID" icon="save">
    Conserver beneficiary_id dans votre base pour faciliter les transactions futures.
  </Card>
  <Card title="Confirmation via IPN" icon="webhook">
    L'API retournera un message immédiat; la confirmation finale de certaines transactions se fera via IPN si le bénéficiaire est lié à une transaction.
  </Card>
</CardGroup>

<Tip>
  La création de bénéficiaires permet de simplifier les transactions futures en réutilisant les informations enregistrées.
</Tip>
