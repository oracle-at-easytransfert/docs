Permet de récupérer les informations complètes d'un bénéficiaire spécifique en utilisant son `beneficiary_id`. Utile pour vérifier ou afficher les données avant d'effectuer une transaction.

<Warning>
  **Note importante :** La gestion des bénéficiaires peut ne pas être disponible dans la version v1 de l'API. Vérifiez la disponibilité de cette fonctionnalité avec le support EASYTRANSFERT.
</Warning>

## Endpoint

```
GET {{base_url}}/beneficiaries/{{beneficiary_id}}
```

## Headers

| Nom | Valeur | Description |
|-----|--------|-------------|
| `Content-Type` | `application/json` | Format de la requête JSON |

## Paramètres

| Champ | Type | Obligatoire | Description |
|-------|------|-------------|-------------|
| `api_key` | string | Oui | Votre clé API EASYTRANSFERT |
| `beneficiary_id` | string | Oui | ID unique du bénéficiaire à consulter |

<Info>
  Dans Postman, `beneficiary_id` est passé dans l'URL ({{base_url}}/beneficiaries/{{beneficiary_id}}) et `api_key` en query string (?api_key={{api_key}}) ou header si nécessaire.
</Info>

## Exemple d'URL

```
{{base_url}}/beneficiaries/BEN.123456?api_key={{api_key}}
```

## Réponse (exemple succès)

```json
{
  "status": "success",
  "message": "Détail du bénéficiaire récupéré",
  "data": {
    "beneficiary_id": "BEN.123456",
    "name": "John Doe",
    "phone": "0670123456",
    "service_id": "11",
    "custom_data": "client_ref_001",
    "created_at": "2026-01-13T12:00:00.000+00:00",
    "updated_at": "2026-01-13T12:15:00.000+00:00"
  }
}
```

## Explications des champs

| Champ | Description |
|-------|-------------|
| `beneficiary_id` | Identifiant unique du bénéficiaire |
| `name` | Nom complet du bénéficiaire |
| `phone` | Numéro de téléphone du bénéficiaire |
| `service_id` | ID du service associé (ex: MTN Cashout = 11) |
| `custom_data` | Données personnalisées pour tracer le bénéficiaire dans votre système |
| `created_at` | Date et heure de création du bénéficiaire |
| `updated_at` | Date et heure de la dernière mise à jour du bénéficiaire |

## Conseils pratiques
