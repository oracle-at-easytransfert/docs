L'API EASYTRANSFERT BUSINESS v1 est une API orientée transaction, et non une API de gestion de compte ou de wallet.

## Absence d'API de gestion de compte

À ce titre, aucun endpoint exposé ne permet actuellement de :

- récupérer les informations générales du compte business (nom du partenaire, identifiant, statut, type de compte, etc.)
- consulter le solde courant du compte partenaire
- vérifier la disponibilité des fonds avant une transaction
- accéder à un historique global des opérations du compte
- gérer un ou plusieurs wallets (création, consultation, sélection)

## Endpoints réellement disponibles (rappel)

L'API v1 expose uniquement les routes suivantes :

| Fonction | Méthode | Endpoint |
|----------|---------|----------|
| Initier une transaction | POST | `/airtime` |
| Vérifier un statut | POST | `/status` |

<Warning>
  Tout autre besoin lié au compte business est hors périmètre de l'API v1.
</Warning>

## Gestion du solde : fonctionnement réel

La gestion du solde du compte partenaire est :

- interne à EASYTRANSFERT
- non exposée via API
- vérifiée côté serveur au moment de l'initiation de la transaction

**Conséquences :**

- une transaction peut être refusée si les fonds sont insuffisants
- aucune requête préalable ne permet de tester la disponibilité du solde
- le développeur ne peut pas anticiper le solde via l'API

## Rôle de la clé API

La clé API :

- identifie le compte business partenaire
- est utilisée pour l'autorisation des transactions
- n'est pas liée à un compte consultable

<Info>
  Il n'existe pas de relation exposée du type : api_key → account_id → balance
</Info>

## Informations financières accessibles indirectement

Certaines informations financières peuvent apparaître dans les notifications IPN, par transaction uniquement :

- `p_last_wallet_amount`
- `p_new_wallet_amount`
- `w_amount_after_transaction`

<Warning>
  **Important :**
  - ces champs ne sont ni contractuels ni garantis
  - ils peuvent être null ou absents
  - ils ne doivent pas être utilisés comme source officielle de solde
</Warning>

## Implications pour les intégrateurs

Les intégrateurs doivent :

- considérer l'API comme asynchrone et événementielle
- baser toute logique métier sur le statut IPN
- maintenir leur propre suivi transactionnel
- ne pas implémenter de logique de solde côté client

<Info>
  L'API EASYTRANSFERT BUSINESS v1 ne fournit aucun endpoint permettant la consultation ou la gestion du compte business. Toute information financière éventuelle transmise via IPN est strictement informative et ne constitue pas une API de solde ou d'historique.
</Info>
