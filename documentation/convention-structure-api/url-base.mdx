La base URL est le point d'entrée principal pour toutes les requêtes de l'API EASYTRANSFERT BUSINESS v1.

## Base URL principale

**Sandbox / Test :**
```
http://proxy-airtime.easytransfert.app/api_v1/transaction
```

**Production :**
L'URL de production sera généralement communiquée après activation du compte.

**Cette URL doit être utilisée pour tous les endpoints, en y ajoutant le chemin spécifique :**

| Endpoint | Chemin complet |
|----------|---------------|
| Initier une transaction (Cashin / Cashout) | `{{base_url}}/airtime` |
| Obtenir le statut d'une transaction | `{{base_url}}/status` |

## Variables Testeur d'API / Environment

Pour faciliter l'intégration dans Testeur d'API, il est recommandé d'utiliser des variables d'environnement :

| Variable | Valeur exemple | Description |
|----------|----------------|-------------|
| `base_url` | `http://proxy-airtime.easytransfert.app/api_v1/transaction` | URL de base pour toutes les requêtes |
| `api_key` | `votre_cle_api_ici` | Clé API EASYTRANSFERT pour l'authentification |
| `transaction_id` | `EFB.001158` | ID de la transaction (utilisé pour /status) |
| `ipn_url` | `http://votre-site.com/webhook/easytransfert` | URL pour recevoir les notifications IPN |

<Warning>
  Le reste des variables `service_id_*` sont utilisées pour identifier le service Cashin/Cashout exact pour chaque opérateur (MTN, Orange, Moov, Flooz).
</Warning>

## Bonnes pratiques

1. **Toujours utiliser la variable {{base_url}}** dans vos requêtes pour pouvoir changer facilement l'environnement (sandbox vs prod).
2. **Ne jamais hardcoder l'URL complète** dans vos scripts, utilisez Testeur d'API Environment.
3. **Vérifier que l'URL utilise HTTPS** en production pour garantir la sécurité des transactions.

## Exemple d'utilisation

**Endpoint pour initier une transaction Airtime (Cashin / Cashout)**
```
POST {{base_url}}/airtime
```

**Endpoint pour obtenir le statut d'une transaction :**
```
POST {{base_url}}/status
```

<Info>
  Les chemins `/airtime` et `/status` s'ajoutent à `{{base_url}}` pour former l'URL complète.
</Info>

<Tip>
  L'utilisation de variables d'environnement facilite la gestion des différents environnements (test, production) sans modifier le code.
</Tip>
