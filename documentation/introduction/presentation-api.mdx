## Objectif de l'API EASYTRANSFERT BUSINESS

L'API EASYTRANSFERT BUSINESS est une API REST qui permet aux marchands d'initier et de suivre leurs transactions.

## Services couverts

L'API couvre exclusivement les services suivants :

### Transferts d'argent Mobile Money

Initiation de transactions Mobile Money via un point d'accès unique.

**Type des transactions :**

- **Cashin** : déplacer de l'argent du wallet du marchand vers le wallet mobile money du client
- **Cashout** : déplacer de l'argent du wallet mobile money du client vers le wallet du marchand

<Info>
  Chaque transaction est identifiée par un `transaction_id` unique généré par EASYTRANSFERT.
</Info>

### Suivi des transactions

Deux mécanismes complémentaires sont disponibles :

<AccordionGroup>
  <Accordion title="IPN (Webhook) - mécanisme recommandé" icon="webhook">
    Notification automatique envoyée à l'URL fournie lors de l'initiation de la transaction.

    Transmission de l'état final de la transaction :

    - **SUCCESS** : Transaction réussie
    - **FAILED** : Transaction échouée
  </Accordion>
  <Accordion title="Consultation du statut (usage limité)" icon="search">
    Endpoint dédié pour récupérer l'état d'une transaction.

    <Warning>
      À utiliser uniquement en cas de non-réception de l'IPN. L'interrogation répétée peut entraîner un blocage.
    </Warning>
  </Accordion>
  <Accordion title="Consultation du solde">
    Endpoint permettant de consulter le solde du marchand.

    <Note>
      Il faut noter que le solde est aussi disponible depuis le dashboard du marchand
    </Note>
  </Accordion>
</AccordionGroup>

## Avantages clés

<AccordionGroup>
  <Accordion title="Sécurité" icon="shield">
    - Authentification par clé API
    - Accès restreint aux partenaires autorisés
    - Communication sécurisée via HTTPS obligatoire
  </Accordion>
  <Accordion title="Traçabilité" icon="file-invoice">
    - Identifiant unique pour chaque transaction
    - Champs custom_data pour le rapprochement métier

  <Accordion title="Scalabilité" icon="chart-bar">
