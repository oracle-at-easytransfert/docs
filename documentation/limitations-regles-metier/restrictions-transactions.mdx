Certaines transactions sont soumises à des règles métier spécifiques en fonction de leur nature, afin d'assurer la sécurité et la conformité.

## Principes

<CardGroup cols={2}>
  <Card title="Transactions Cashin / Cashout" icon="exchange-alt">
    - **Cashin** (ajout d'argent) : permet d'alimenter le mobile money d'un bénéficiaire depuis votre compte partenaire.
    - **Cashout** (retrait) : permet de retirer de l'argent du mobile money du bénéficiaire vers votre compte partenaire.
    - Chaque type a ses propres limites et conditions.
  </Card>
  <Card title="Transactions de test vs production" icon="flask">
    - Les transactions en Sandbox n'impactent pas de vrais comptes.
    - Les transactions en Production sont réelles et irréversibles.
  </Card>
  <Card title="Transactions critiques" icon="exclamation-triangle" color="#dc2626">
    Pour les transactions supérieures à certains montants ou à fort enjeu, l'API peut exiger une validation ou confirmation supplémentaire. La confirmation finale est toujours transmise via webhook IPN.
  </Card>
</CardGroup>

## Bonnes pratiques

<CardGroup cols={2}>
  <Card title="Séparer Cashin et Cashout" icon="arrows-alt-h">
    Utilisez les service_id corrects pour chaque type de transaction. Exemple : MTN Cashin = service_id_mtn_cashin ; MTN Cashout = service_id_mtn_cashout.
  </Card>
  <Card title="Limiter les tests en production" icon="ban">
    Ne testez jamais des montants fictifs en environnement Production.
  </Card>
  <Card title="Suivi via IPN" icon="webhook" color="#1d60d5">
    Les transactions critiques ne doivent pas être suivies uniquement via /status. Les webhooks IPN garantissent un suivi fiable et sécurisé.
  </Card>
</CardGroup>

## Exemple pratique

**Scénario :** Un utilisateur souhaite effectuer un Cashout MTN de 500 000 FCFA.

**Vérifications à effectuer :**

<Steps>
  <Step title="Vérifier le montant">
    Montant ≤ plafond maximum pour MTN Cashout (500 000 FCFA).
  </Step>
  <Step title="Vérifier le numéro">
    Numéro de bénéficiaire valide et local.
  </Step>
  <Step title="Vérifier le service ID">
    Service ID correct utilisé (service_id_mtn_cashout).
  </Step>
  <Step title="Suivre via IPN">
    Suivi via IPN pour confirmation finale.
  </Step>
</Steps>

<Tip>
  Assurez-vous toujours d'utiliser le bon service_id pour le type de transaction (Cashin ou Cashout) et l'opérateur choisi.
</Tip>
