Avant toute requête, il est nécessaire de configurer les variables d'environnement.

## Variables obligatoires

| Variable | Description |
|----------|-------------|
| `base_url` | URL de base de l'API |
| `api_key` | Clé API fournie par EASYTRANSFERT |
| `ipn_url` | URL de votre webhook pour recevoir les notifications |
| `service_id_*` | Identifiants des services (Cashin / Cashout) |

## Exemple (Environment Testeur d'API)

```json
{
  "base_url": "http://proxy-airtime.easytransfert.app/api_v1/transaction",
  "api_key": "votre_cle_api_ici",
  "ipn_url": "https://votre-site.com/webhook/easytransfert"
}
```

## Bonnes pratiques

<Tip>
  **Sécurité :**
  - La variable `api_key` doit être définie comme secret dans Testeur d'API
  - L'`ipn_url` doit être accessible publiquement en HTTPS
  - Les `service_id` doivent être validés par EASYTRANSFERT
</Tip>

<Warning>
  Ne jamais exposer la clé API dans le code source ou les logs. Toujours utiliser des variables d'environnement sécurisées.
</Warning>
