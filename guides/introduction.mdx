Les solutions API Easy Transferts [API Paiement (Cash-in)](/guides/paiements/introduction) et [Transfert (Cash-out)](/guides/transferts/introduction) offrent une intégration standardisée et sécurisée pour les transactions financières en ligne. Ces solutions prennent en charge le mode de paiement Mobile Money

Pour commencer à intégrer l'API Easy Transfert, il est essentiel de suivre les étapes et les concepts détaillés dans ce guide de démarrage, qui met en exergue les bases du reste du processus d'intégration.

[Un dictionnaire](/documentation/dictionnaire) est également disponible pour vous aider à comprendre les termes utilisés dans cette documentation.
